# Lacerda & Garcez · Sociedade de Advogados

Site institucional em HTML, CSS e JavaScript puros (sem build). O CSS e o JS estão embutidos no `index.html`.

## Estrutura

- `index.html`: página completa
- `assets/socios.jpg`: foto dos sócios
- `assets/redbox.png`: logo da Agência RedBox (crédito do rodapé)

## Como usar

Abra `index.html` no navegador ou publique a pasta em qualquer hospedagem estática (GitHub Pages, Vercel, Netlify). As fontes (Cormorant Garamond, Cinzel e Source Serif 4) são carregadas do Google Fonts.

Desenvolvido pela Agência RedBox.
